# 3SecVideos

Единое приложение для отбора коротких видео и скриншотов на macOS. Оно использует принудительно тёмный интерфейс, системные диалоги Finder для выбора папок и показывает журнал, прогресс и итоговую сводку.

## Запуск

```bash
python3 run.py
```

Интерпретатор Python должен включать Tkinter. Если Tkinter отсутствует, приложение завершится с явным сообщением об этой зависимости.

## Режимы

- «Короткие видео» рекурсивно ищет `.mp4`, `.avi`, `.mov` и `.mkv`. Порог длительности по умолчанию — 3 секунды, его можно менять с шагом 0,1. Подходящие файлы можно переместить с сохранением подпапок или отправить в Корзину macOS.
- «Скриншоты» ищет изображения с признаком `Screenshot` в метаданных и только перемещает их в выбранную папку.

Кнопка «Предпросмотр» выполняет полный поиск и проверку без изменения файлов. Целевая папка не может совпадать с исходной или находиться внутри неё; существующие файлы назначения не перезаписываются.

Для видео нужен `ffprobe` из FFmpeg, для скриншотов — пакет Pillow. При отсутствии выбранной зависимости приложение объяснит причину и предложит установку. Установка начинается только после явного подтверждения пользователя.
