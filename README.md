# 3SecVideos

Единое приложение для отбора коротких видео и скриншотов на macOS. Оно использует тёмный интерфейс, системные диалоги Finder для выбора папок и показывает журнал, прогресс и итоговую сводку.

## Запуск

```bash
python3 run.py
```

Если текущий `python3` не содержит Tkinter (например, Python из pyenv), скрипт автоматически перезапустится через современный Python Homebrew с Tkinter.

### Первый запуск

Для графического окна нужен современный Tkinter. Установите его один раз:

```bash
brew install python-tk@3.14
```

После этого запускайте приложение обычной командой `python3 run.py`. Не нужно вручную выбирать другой интерпретатор Python.

Для режима скриншотов нужен Pillow. Приложение предложит установить его в используемый Python только после вашего подтверждения. При необходимости его можно установить заранее:

```bash
python3 -m pip install -r requirements.txt
```

Для режима видео нужен FFmpeg. При необходимости приложение также предложит установку; ручная команда:

```bash
brew install ffmpeg
```

## Режимы

- «Короткие видео» рекурсивно ищет `.mp4`, `.avi`, `.mov` и `.mkv`. Порог длительности по умолчанию — 3 секунды, его можно менять с шагом 0,1. Порог включающий: значение `4` обработает видео длительностью до 4 секунд включительно. Подходящие файлы можно переместить с сохранением подпапок или отправить в Корзину macOS.
- «Скриншоты» ищет изображения с признаком `Screenshot` в метаданных и только перемещает их в выбранную папку.

В обоих режимах сначала выберите исходную папку кнопкой «Выбрать…». Для перемещения выберите также целевую папку. Кнопка «Предпросмотр» выполняет полный поиск и проверку без изменения файлов.

Целевая папка не может совпадать с исходной или находиться внутри неё, включая ссылки и варианты пути с другим регистром. Существующие файлы назначения не перезаписываются: к совпадающему имени добавляется суффикс `_1`, `_2` и далее. Удаление видео отправляет файлы в Корзину macOS, а не удаляет безвозвратно.

Во время обработки в окне отображаются количество обработанных файлов (`N из M`), процент, индикатор прогресса, построчный журнал и итог по перемещённым, пропущенным и ошибочным файлам.
