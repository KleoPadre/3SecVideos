# Единое приложение обработки медиа

## Цель

Заменить разрозненные сценарии обработки видео и скриншотов единым macOS-приложением с тёмным графическим интерфейсом. Единственная команда запуска — `python3 run.py`.

## Интерфейс

Окно на Tkinter всегда использует тёмную палитру. В верхней части пользователь выбирает режим: «Короткие видео» или «Скриншоты». Кнопки «Выбрать…» открывают системные диалоги Finder для выбора исходной и целевой папок, поэтому пути не нужно вводить вручную.

В режиме видео доступно числовое поле максимальной длительности с шагом 0,1 секунды и значением 3 по умолчанию. Сравнение включающее: значение 4 обрабатывает видео длительностью до 4,00 секунды включительно. Также доступен выбор действия: переместить или отправить в Корзину.

В режиме скриншотов приложение ищет изображения, в метаданных которых есть `Screenshot`, и перемещает их в выбранную папку. Отправка скриншотов в Корзину не входит в интерфейс.

Для обоих режимов предусмотрены кнопки «Предпросмотр» (без изменения файлов) и «Запустить обработку».

## Обработка и прогресс

Перед началом операции приложение рекурсивно собирает подходящие файлы. Затем выводит в журнал и отдельную строку прогресса: обработано `N из M`, процент и индикатор. Каждая операция добавляет строку с результатом. После завершения выводится итог по найденным, перемещённым, отправленным в Корзину, пропущенным и ошибочным файлам.

Перемещение сохраняет структуру подпапок и не перезаписывает существующие файлы: при конфликте добавляется суффикс `_1`, `_2` и далее. Целевая папка не может совпадать с исходной или находиться внутри неё. Удаление видео выполняется через Корзину macOS.

## Зависимости

`run.py` проверяет зависимости при запуске. Для видео требуется `ffprobe` из FFmpeg; для скриншотов — Python-пакет Pillow. Если компонента нет, приложение объясняет причину и предлагает установить его после явного подтверждения: FFmpeg через Homebrew, Pillow через текущий интерпретатор Python. Виртуальное окружение не обязательно, так как Pillow устанавливается только при выборе режима скриншотов и подтверждении пользователя.

## Структура проекта

- `run.py` — единственная точка запуска и весь прикладной код: UI, проверка зависимостей, поиск и обработка файлов.
- `tests/test_run.py` — тесты независимых функций отбора, путей, итогов и проверок входных данных.
- `README.md` — краткий запуск, описание обоих режимов и зависимостей.
- `requirements.txt` — единственная внешняя Python-зависимость: Pillow.

Устаревшие `video_filter.py`, `mov.py` и `iphone_screens.py` удаляются, чтобы исключить несколько способов запуска.

## Проверка

Тесты на `unittest` покрывают границу длительности, выбор свободного пути, распознавание метаданных `Screenshot`, режим предпросмотра, ход прогресса и валидацию папок. Дополнительно запускается `python3 run.py` для проверки создания окна и выполняется ручная проверка выбора папок, прогресса и журнала.
